# h2cov

**h2cov** is a lightweight HTTP/2-based code coverage server written in C++.  
It allows users to upload source files via HTTP/2, automatically extract and analyze them, and retrieve line-level coverage results in a simple RESTful manner.

---

## Features

- **HTTP/2 Support**: Designed from scratch with nghttp2 and epoll to support modern HTTP/2 clients.
